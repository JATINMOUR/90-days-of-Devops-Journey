# Process Management and Performance Monitoring

Commands for managing active Linux processes, background jobs, resource utilization, and system performance diagnostics.

| Command | Description |
| :--- | :--- |
| `&` | Append to end of command string to execute process in the background. |
| `ps` | Print active system process snapshot. Commonly used as `ps aux`. |
| `ps -e` / `ps -A` | Display list of every running system process. |
| `ps -ef` | Print full-format list including parent process IDs (PPID). |
| `ps -U root -u root` | Output all active process tasks owned by user `root`. |
| `ps -eo pid,user,command` | Customize output display to show Process ID, User, and Command columns only. |
| `top` | Display real-time dynamic view of process activity and resource usage. |
| `htop` | Interactive process viewer with color-coded UI indicators and scrolling features. |
| `atop` | Advanced system performance monitor highlighting hardware and process load bottlenecks. |
| `kill PID` | Terminate specified process by Process ID number (`PID`). |
| `killall proc1` | Send termination signal to all processes matching name `proc1`. |
| `lsof` | List open files and associated process bindings. |
| `lsof -u root` | List all open file handles owned specifically by user `root`. |
| `mpstat 1` | Output CPU processor statistics, refreshing every 1 second. |
| `vmstat 1` | Output virtual memory, swap usage, IO, and CPU activity metrics refreshed per 1 sec. |
| `iostat 1` | Print terminal block device standard I/O statistics updated every second. |
| `tail -n 100 /var/log/messages` | View last 100 entries of system logs (or `/var/log/syslog` on Ubuntu/Debian). |
| `tcpdump -i eth0` | Capture network interface network packet frames on device `eth0`. |
| `tcpdump -i eth0 port 80` | Monitor HTTP traffic specifically over port `80` on interface `eth0`. |
| `watch df -h` | Periodically repeat `df -h` execution continuously (Exit: `Ctrl+C`). |
