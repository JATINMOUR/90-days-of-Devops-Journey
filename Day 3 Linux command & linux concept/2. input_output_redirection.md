# Input/Output Redirection

Commands and syntax for managing standard input, standard output, and standard error streams in Linux.

| Command / Syntax | Description |
| :--- | :--- |
| `echo TEXT` | Display a string of `TEXT` or variable contents to stdout. |
| `echo -e TEXT` | Enable interpretation of backslash escape sequences (e.g., `\n` for newline, `\t` for tab). |
| `echo -n TEXT` | Omit trailing newline character when outputting text. |
| `cmd > file` | Redirect stdout of `cmd` into `file` (overwrites existing content). |
| `cmd >& file` | Redirect both stdout and stderr of `cmd` to `file` (overwrites content). |
| `cmd > /dev/null` | Discard standard output of `cmd` completely. |
| `cmd >> file` | Append output of `cmd` to the end of `file`. |
| `cmd < file` | Read input for `cmd` from standard content of `file`. |
| `cmd << delim` | **Here-document:** Read multi-line standard input into `cmd` until line containing `delim` is encountered. |
| `cmd <<< string` | **Here-string:** Pass string directly as standard input to `cmd`. |
| `cmd 2> foo` | Redirect standard error messages (`stderr`) of `cmd` into file `foo`. |
| `cmd 2>> foo` | Append standard error messages (`stderr`) of `cmd` to file `foo`. |
| `cmd &> file` | Redirect both stdout and stderr of `cmd` into `file`. |
