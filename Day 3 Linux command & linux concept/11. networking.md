# Networking

Commands for configuring network interfaces, inspecting network connections, running diagnostics, and downloading content over protocols.

| Command | Description |
| :--- | :--- |
| `ifconfig` | Display active network interface configuration, assigned IP addresses, and flags. |
| `ifconfig -a` | Display all network interfaces (including inactive or down interfaces). |
| `ifconfig eth0` | Show details and assigned IP addresses for target interface `eth0`. |
| `ip a` | Modern tool (`iproute2`) to display interface standard addresses. |
| `ethtool eth0` | Query physical parameters, driver status, and speed capabilities of link `eth0`. |
| `netstat` | Display active open network sockets, routing tables, and interface statistics. |
| `netstat -a` | Print listening and non-listening protocol sockets. |
| `netstat -l` | Filter netstat display to output active listening sockets only. |
| `netstat -nutlp` | Display numerical TCP/UDP listening ports alongside bound Process IDs. |
| `ping host` | Send ICMP ECHO_REQUEST packets to `host` IP or domain to test connectivity. |
| `whois domain` | Retrieve domain registrar WHOIS contact information records. |
| `dig domain` | Perform DNS lookup queries and resolve server domain records. |
| `dig -x addr` | Execute reverse DNS resolution query on target IPv4/IPv6 address string. |
| `host domain` | Simple utility for looking up IP hostnames or domain mappings. |
| `wget LINK` | Download files over HTTP, HTTPS, or FTP protocol links. |
| `curl LINK` | Fetch and print standard raw web response content from specified URL endpoint. |
| `ufw allow port` | Configure Uncomplicated Firewall (UFW) rule allowing incoming traffic over `port`. |
| `ufw status` | Check current operational status and active rule list of UFW firewall. |
| `nmcli` | Command-line tool for managing NetworkManager configurations and links. |
