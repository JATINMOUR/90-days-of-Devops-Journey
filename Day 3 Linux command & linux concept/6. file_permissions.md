# File Permissions

Commands and notation system for controlling read, write, and execute permissions on Linux systems.

## Permission Structure
`- rwx rw- r--`
* First character: File type (`-` regular file, `d` directory, `l` symbolic link)
* First triplet (`rwx`): Owner/User (`u`) privileges
* Second triplet (`rw-`): Group (`g`) privileges
* Third triplet (`r--`): Others (`o`) privileges

| Permission Symbol | Mode | Numeric Value | Description |
| :---: | :---: | :---: | :--- |
| `r` | Read | 4 | Allows reading file contents / listing directory entries |
| `w` | Write | 2 | Allows modifying file contents / creating files in directory |
| `x` | Execute | 1 | Allows running file as program / entering directory |

## Octal Representation Table

| Octal | Permission Notation | Symbolic Equivalent | Description |
| :---: | :---: | :---: | :--- |
| `0` | `---` | `-rwx` | No permissions |
| `1` | `--x` | `=x` | Execute permission only |
| `2` | `-w-` | `=w` | Write permission only |
| `3` | `-wx` | `=wx` | Write and execute permissions ($2+1=3$) |
| `4` | `r--` | `=r` | Read permission only |
| `5` | `r-x` | `=rx` | Read and execute permissions ($4+1=5$) |
| `6` | `rw-` | `=rw` | Read and write permissions ($4+2=6$) |
| `7` | `rwx` | `=rwx` | Read, write, and execute permissions ($4+2+1=7$) |

## Management Commands

| Command | Description |
| :--- | :--- |
| `chmod permission file` | Change access permissions of a file/directory (uses octal or symbolic syntax). |
| `chown user2 file` | Change ownership of `file` to `user2`. |
| `chgrp group2 file` | Change group ownership of `file` to `group2`. |

### Examples

* `chmod +x testfile` - Grant execute access to user, group, and others.
* `chmod u-w testfile` - Remove write permission for file owner.
* `chmod u+wx,g-x,o=rx testfile` - Grant owner write/execute, revoke group execute, set others permissions to read/execute.
* `chmod 777 testfile` - Grant read, write, and execute permissions to everyone.
* `chmod 177 testfile` - Restrict owner to execute-only (`1`), group & others receive full access (`7`).
* `chmod 365 testfile` - Owner: Write/Execute (`3`), Group: Read/Write (`6`), Others: Read/Execute (`5`).
