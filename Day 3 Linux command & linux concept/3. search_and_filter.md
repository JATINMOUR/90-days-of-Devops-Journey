# Search and Filter

Commands used to locate files or search within file contents using text patterns.

| Command | Description |
| :--- | :--- |
| `grep patt /path/to/src` | Search for pattern `patt` inside files at given path. |
| `grep -r patt /path/to/src` | Recursively search for `patt` in specified directory and all subdirectories. |
| `grep -v patt X` | Invert match: Display lines in file `X` that do *not* match `patt`. |
| `grep -l patt X` | Print only file names containing the matching pattern `patt`. |
| `grep -i patt X` | Perform case-insensitive pattern matching on file `X`. |
| `find` | Search directory hierarchy for files and directories. |
| `find /path/to/src -name "*.sh"` | Find all files matching filename pattern `*.sh` under specified directory. |
| `find /home -size +100M` | Find all files larger than 100 Megabytes under `/home`. |
| `locate name` | Search system database for matching filenames quickly. |
| `sort X` | Sort lines in text file `X` alphabetically or numerically. |
