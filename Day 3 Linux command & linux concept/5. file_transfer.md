# File Transfer

Tools and commands used to transfer files and connect securely between local and remote machines.

| Command | Description |
| :--- | :--- |
| `ssh user@access` | Secure shell connection to host `access` as specified `user`. |
| `ssh access` | Connect to remote host `access` using local user session name. |
| `ssh -p port user@access` | Connect to host `access` over custom SSH port. |
| `scp [user1@]host1:[path1] [user2@]host2:[path2]` | Copy files via Secure Copy Protocol between local/remote destinations. |
| `scp -P port [user1@]host1:[path1] [path2]` | SCP copy specifying network port number. |
| `scp -r [user1@]host1:[path1] [path2]` | Recursively copy entire directory tree via SCP. |
| `sftp [user@]access` | Open interactive Secure File Transfer Protocol session on `access`. |
| `sftp -P port user@access` | Open SFTP session over specified custom port. |
| `rsync -a [path1] [path2]` | Sync `path1` to `path2` preserving symlinks, attributes, permissions, and timestamps. |
| `rsync -avz host1:[path1] [path2]` | Synchronize remote path to local directory, enabling compression (`-z`) and verbose mode (`-v`). |
