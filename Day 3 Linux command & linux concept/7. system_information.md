# System Information

Commands for retrieving system details, hardware profiles, uptime, and general host status.

## General & OS Information

| Command | Description |
| :--- | :--- |
| `uname` | Print system kernel architecture name. |
| `uname -a` | Print comprehensive system details (kernel version, architecture, hostname). |
| `uname -r` | Output kernel release version. |
| `uptime` | Display system operational uptime duration and system load averages. |
| `su` / `sudo` | Execute commands with root superuser capabilities. |
| `cal` | Output terminal calendar highlighting current day date. |
| `date` | Display or set current system date and time. |
| `halt` | Stop system services immediately. |
| `shutdown` | Gracefully shut down operating system. |
| `reboot` | Restart machine system. |
| `last reboot` | View log history of system restarts. |
| `man COMMAND` | Open manual documentation for specified `COMMAND` (Press `q` to quit). |
| `hostname` | Print local network hostname. |
| `hostname -I` | Display system network IP interface addresses. |
| `cat /etc/*-release` | View installed distribution release version details. |

## Hardware Information

| Command | Description |
| :--- | :--- |
| `dmesg` | Print kernel buffer ring diagnostic logs. |
| `cat /proc/cpuinfo` | Show CPU hardware metrics and specifications. |
| `cat /proc/meminfo` | Detailed virtual/physical memory usage statistics. |
| `lspci -tv` | Display PCI devices formatted as tree diagram (`-t`) with verbosity (`-v`). |
| `lsusb -tv` | Output connected USB device status tree. |
| `dmidecode` | Read system BIOS DMI table for hardware components/serials. |
| `hdparm -i /dev/sda` | View hardware specs for storage disk device `sda`. |
| `hdparm -tT /dev/sda` | Run cache and device read performance tests on disk `sda`. |
| `badblocks -s /dev/sda` | Scan storage unit `/dev/sda` for bad unreadable sectors. |
