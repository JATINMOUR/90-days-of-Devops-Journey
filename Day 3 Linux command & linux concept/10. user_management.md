# User Management

Commands for managing users, groups, system access, and tracking user activity.

| Command | Description |
| :--- | :--- |
| `who` | Output list of logged-in user accounts. |
| `w` | Show currently active users along with their running terminal processes. |
| `users` | Output usernames currently connected to system session. |
| `whoami` | Display active user login context name. |
| `id` | Output user ID (`UID`) and associated group membership identifiers (`GID`). |
| `last` | Show historic timeline list of user logins and reboots. |
| `groupadd gp1` | Create new system user group named `gp1`. |
| `useradd -c "Alice Bob" -m ab1` | Create account `ab1` with user comment field and home directory setup. |
| `userdel ab1` | Permanently remove user account `ab1`. |
| `usermod -aG gp1 ab1` | Append existing user account `ab1` into supplementary group `gp1`. |
