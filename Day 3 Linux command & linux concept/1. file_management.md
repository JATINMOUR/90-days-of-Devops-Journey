# File Management

Essential Linux commands for navigating, managing, and manipulating files and directories.

| Command | Description |
| :--- | :--- |
| `*` | Wildcard symbol for variable length, e.g., `*.txt` refers to all files with the TXT extension. |
| `?` | Wildcard symbol referring to a single character, e.g., `Doc?.docx` can refer to `Doc1.docx`, `DocA.docx`, etc. |
| `ls` | List the names of files and subfolders in the current directory. Options include `-l`, `-a`, `-t` which you may combine (e.g., `-alt`). |
| `ls -l` | Show details of each item displayed, such as permissions, owner, size, and last modified date/time. |
| `ls -a` | Display hidden files/folders (starting with `.`). May be combined with `ls -l` as `ls -al`. |
| `ls -t` | Sort files/folders by last modified date/time, starting with the most recently modified. |
| `cd` | Navigate to the `$HOME` directory. |
| `cd ..` | Move up one level to the parent directory. |
| `cd /etc` | Navigate directly to the `/etc` directory. |
| `cmp A B` | Compare two files A and B for sameness. Outputs nothing if identical; otherwise outputs byte and line number where they differ. |
| `diff A B` | Compare two files line-by-line and display differences. |
| `pwd` | Display the absolute path of the current working directory. |
| `mkdir X` | Create a new directory named `X` in the current working directory. |
| `mv A B` | Move a file from path A to path B, or rename it. <br>• Move: `mv ./folder1/file.txt ./folder2/`<br>• Rename: `mv new_doc.txt expenses.txt` |
| `cp A B` | Copy a file from path A to path B. <br>• Example: `cp ./f1/file.txt ./f2/expenses.txt` (copies and renames) |
| `cp -r Y Z` | Recursively copy directory `Y` and all its contents to `Z`. |
| `rm X` | Permanently remove file `X`. |
| `rm -r Y` | Recursively delete directory `Y` and its contents. |
| `rm -f X` | Forcibly remove file `X` without prompt confirmation. |
| `rm -rf Y` | Forcibly and recursively remove directory `Y` and its contents. |
| `rmdir Y` | Permanently remove directory `Y`, provided it is empty. |
| `open X` | Open file `X` in its default system application. |
| `open -e X` | Open file `X` in standard text editor (macOS). |
| `touch X` | Create an empty file `X` or update access and modification timestamps of `X`. |
| `cat X` | View the full contents of file `X`. |
| `cat -b X` | View contents of `X` with non-empty line numbers displayed. |
| `wc X` | Display word, line, and byte count of file `X`. |
| `head X` | Display the first 10 lines of file `X`. |
| `head -n 4 X` | Display the first 4 lines of file `X`. |
| `tail X` | Display the last 10 lines of file `X`. |
| `tail -n +1 X` | Display contents starting from line 1 with file header header info. |
| `tail -f X` | Track changes appended to file `X` in real-time (useful for log files). |
| `less X` | View file `X` with forward/backward page navigation (useful for large files). |
| `ln -s A S` | Create a symbolic link named `S` pointing to file or directory path `A`. |
