# Archives

Utilities for creating, viewing, and extracting compressed and uncompressed archive files (`tar`, `gz`, `bz2`, `zip`).

| Command | Description |
| :--- | :--- |
| `tar` | Utility for manipulating tape archives (`.tar`). |
| `tar -v` | Provide verbose output listing files processed during archiving/extraction. |
| `tar -cf archive.tar Y` | Create an uncompressed TAR archive `archive.tar` containing file/directory `Y`. |
| `tar -xf archive.tar` | Extract files from `archive.tar`. |
| `tar -tf archive.tar` | List contents of `archive.tar` without extracting. |
| `tar -czf archive.tar.gz Y` | Create a gzip-compressed TAR archive (`.tar.gz`) containing `Y`. |
| `tar -xzf archive.tar.gz` | Extract gzip-compressed TAR archive (`.tar.gz`). |
| `tar -cjf archive.tar.bz2 Y` | Create a bzip2-compressed TAR archive (`.tar.bz2`) containing `Y`. |
| `tar -xjf archive.tar.bz2` | Extract bzip2-compressed TAR archive (`.tar.bz2`). |
| `gzip Y` | Compress file `Y` into `Y.gz` and replace original file. |
| `gzip -l Y.gz` | Display compressed size and uncompressed size details of `Y.gz`. |
| `gzip -d Y.gz` / `gunzip Y.gz` | Decompress `Y.gz` archive back into original file `Y`. |
| `bzip2 Y` | Compress file `Y` into `Y.bz2`. |
| `bzip2 -d Y.bz2` / `bunzip2 Y.bz2` | Decompress `Y.bz2` back into original file `Y`. |
| `zip -r Z.zip Y` | Compress folder/file `Y` recursively into `Z.zip`. |
| `unzip Z.zip` | Unpack `Z.zip` into current working directory. |
| `unzip -l Z.zip` | List contents of `Z.zip` without extracting. |
