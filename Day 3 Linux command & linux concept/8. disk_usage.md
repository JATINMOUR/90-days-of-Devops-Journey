# Disk Usage

Commands to inspect mounted filesystems, storage space allocations, partition details, and RAM usage.

| Command | Description |
| :--- | :--- |
| `df` | Display available and used filesystem space usage. |
| `du` | Output disk space occupied by directories and sub-files. |
| `du -ah` | Show sizes of all files and folders in human-readable units (KB, MB, GB). |
| `du -sh` | Summarize total space consumed by current working directory. |
| `du -h` | View mounted filesystem space using human-readable metrics. |
| `du -i` | Display inode consumption and availability across filesystems. |
| `fdisk -l` | List storage partitions, partition types, and size specifications. |
| `free -h` | View free and used RAM/Swap space in human-readable units. |
| `free -m` | View free and used RAM/Swap allocation expressed in Megabytes (MB). |
| `free -g` | View free and used RAM/Swap allocation expressed in Gigabytes (GB). |
