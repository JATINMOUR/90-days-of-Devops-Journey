# Package Management

Comparative table of package management operations across major Linux distribution families.

| Task | Debian / Ubuntu (`apt` / `dpkg`) | RHEL / Fedora / Rocky (`dnf`) | Arch Linux (`pacman`) |
| :--- | :--- | :--- | :--- |
| **Update repository package lists** | `sudo apt update` | `dnf check-update` | `pacman -Syy` *(Note: `pacman -Syu` preferred)* |
| **Upgrade installed packages** | `sudo apt upgrade` | `sudo dnf upgrade` | `pacman -Syu` |
| **Search package by keyword** | `apt search keyword` | `dnf search keyword` | `pacman -Ss keyword` |
| **View package details & summary** | `apt show package` | `dnf info package` | `pacman -Si package` |
| **Install package file / repo item** | `sudo dpkg -i package.deb`<br>`sudo apt install package` | `sudo dnf install package.rpm` | `pacman -S package` |
| **Uninstall / Remove package** | `sudo apt remove package` | `sudo dnf erase package` | `pacman -R package` |
