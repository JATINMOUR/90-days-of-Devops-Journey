## Strings & Formatting

Strings are scalar values with no size limit.

### Quotes
* `"Double Quotes"`: Preserves literals, but allows variable expansion (`$`) and escape characters (`\`).
* `'Single Quotes'`: Preserves all literal text (no variable expansion).
* `` `Backticks` ``: Used for command substitution (executes command).

**Example (`quotes.sh`):**
```bash
#!/bin/bash
single='Single quoted'
double="Double quoted"

echo $single
echo $double
```

### Escape Characters with `echo -e`

| Sequence | Description |
| :--- | :--- |
| `-n` | Do not output the trailing newline |
| `-e` | Enable interpretation of backslash escapes |
| `\a` | Alert (bell) |
| `\b` | Backspace |
| `\c` | Suppress trailing newline |
| `\n` | Newline |
| `\r` | Carriage return |
| `\t` | Horizontal tab |
| `\\` | Backslash |
