## What is a Shell Script?

In the simplest terms, a shell script is a file containing a series of commands. The shell reads this file and carries out the commands as though they have been entered directly on the command line.

Normally, shell scripts have the file extension `.sh`.

To create a shell script, you use a text editor. There are many text editors available for your Linux system, both for the command-line environment and the GUI environment. Here is a list of some common ones:

1. **vi or vim**: Command-line interface text editor.
2. **gedit**: GUI text editor.

---

### Steps to Write and Run a Shell Script

**Step 1:** Use any editor (like `vi` or `gedit`) to write the shell script.

```bash
vi hello.sh
```

**Step 2:** After writing the shell script, set execute permissions for your script.

```bash
chmod +x <script_file_name>
# OR
chmod 755 <script_file_name>
```

> **Note:** `chmod 755` sets **Read, Write, and Execute (7)** permissions for the owner, and **Read and Execute (5)** permissions for group and others.

**Step 3:** Execute your script:

```bash
bash <script_file_name>
# OR
sh <script_file_name>
# OR
./<script_file_name>
```

---

### Basic Example

```bash
vi shub.sh
```

**Content:**
```bash
#!/bin/sh
echo "Hello welcome to The DevOps Learning!"
```

**Give execution permissions and run:**
```bash
chmod +x shub.sh
./shub.sh
```

**Output:**
```text
Hello welcome to The DevOps Learning!
```
