### 3. `awk`

`awk` is a powerful text processing tool and programming language suited for data extraction, report generation, and math calculations on tabular data.

#### How `awk` Works
`awk` reads input line-by-line and splits each line into fields (columns) using space or tab as default delimiters.

* `$0`: Entire line
* `$1, $2, $3...`: Column numbers
* `NR`: Number of Records (current line number)
* `NF`: Number of Fields (total columns in current line)
* `-F<delimiter>`: Set custom field delimiter

#### `awk` Syntax
```bash
awk 'pattern {action}' filename
```

#### `awk` Examples

* **Print all contents of a file:**
  ```bash
  awk '{print $0}' dosum.sh
  ```
* **Print matching lines containing "bash" across `.sh` files:**
  ```bash
  awk '/bash/{print $0}' *.sh
  ```
* **Print list of files starting with `#!/bin/bash`:**
  ```bash
  awk '/^#!\/bin\/bash/{print $0, FILENAME}' *
  ```
