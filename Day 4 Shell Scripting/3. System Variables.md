### System Variables

Created and maintained by the Linux Bash shell itself. Defined in **UPPERCASE**.

To see all system variables, run:
```bash
env
# OR
printenv
```

**Example (`system_variables.sh`):**
```bash
#!/bin/bash
echo "BASH=$BASH"
echo "BASH_VERSION=$BASH_VERSION"
echo "HOSTNAME=$HOSTNAME"
echo "TERM=$TERM"
echo "SHELL=$SHELL"
echo "HISTSIZE=$HISTSIZE"
echo "USER=$USER"
echo "HOME=$HOME"
echo "PWD=$PWD"
```
