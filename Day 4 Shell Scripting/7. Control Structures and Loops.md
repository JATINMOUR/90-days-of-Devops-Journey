## Control Flow Statements

### `if` Control Statement

**Syntax:**
```bash
if [ condition ]
then
    # Commands if condition is true
elif [ condition2 ]
then
    # Commands if condition2 is true
else
    # Commands if no conditions are true
fi
```

**Example 1: Find Largest Number (`FindBiggestNumber.sh`)**
```bash
#!/bin/bash

if [ $# -ne 3 ]
then
    echo "$0: number1 number2 number3 are not given" >&2
    exit 1
fi

n1=$1
n2=$2
n3=$3

if [ $n1 -gt $n2 ] && [ $n1 -gt $n3 ]
then
    echo "$n1 is the biggest number"
elif [ $n2 -gt $n1 ] && [ $n2 -gt $n3 ]
then
    echo "$n2 is the biggest number"
elif [ $n3 -gt $n1 ] && [ $n3 -gt $n2 ]
then
    echo "$n3 is the biggest number"
elif [ $1 -eq $2 ] && [ $1 -eq $3 ]
then
    echo "All the three numbers are equal"
else
    echo "I cannot figure out which number is bigger"
fi
```

**Example 2: Check File Existence & Permissions (`FileExists.sh`)**
```bash
#!/bin/bash
echo -e "Enter the name of the file: \c"
read file_name

if [ -f "$file_name" ]
then
    if [ -w "$file_name" ]
    then
        echo "Type something. To Quit, press Ctrl + D:"
        cat >> "$file_name"
    else
        echo "The file does not have write permissions."
    fi
else
    echo "$file_name does not exist."
fi
```

### `for` Loop

**Syntax:**
```bash
for (( initialization; condition; increment ))
do
    # Commands
done
```

**Example (`for_loop.sh`):**
```bash
#!/bin/bash
echo "Can you see the following:"
for (( i=1; i<=5; i++ ))
do
    echo $i
done
```

**Output:**
```text
Can you see the following:
1
2
3
4
5
```

### `while` Loop

**Syntax:**
```bash
while [ condition ]
do
    # Commands
done
```

**Example:**
```bash
#!/bin/bash
i=5
while [ $i -ne 0 ]
do
    echo "$i"
    i=`expr $i - 1`
done
```

**Output:**
```text
5
4
3
2
1
```

### `case` Statement (Switch Case)

The `case` statement is a cleaner alternative to multi-level `if-elif-else` blocks when matching a variable against multiple values.

**Syntax:**
```bash
case $variable in
    pattern1)
        # Commands
        ;;
    pattern2)
        # Commands
        ;;
    *)
        # Default commands
        ;;
esac
```

**Example (`switch_case.sh`):**
```bash
#!/bin/sh
echo "Enter a number between 1 and 10:"
read NUM

case $NUM in
    1) echo "You entered one" ;;
    2) echo "You entered two" ;;
    3) echo "You entered three" ;;
    4) echo "You entered four" ;;
    5) echo "You entered five" ;;
    6) echo "You entered six" ;;
    7) echo "You entered seven" ;;
    8) echo "You entered eight" ;;
    9) echo "You entered nine" ;;
    10) echo "You entered ten" ;;
    *) echo "INVALID NUMBER!" ;;
esac
```

## Advanced Text Processing Commands

### 1. `grep` & `egrep`

* `grep`: Utility that searches for pattern matches in files or piped input.
* `egrep`: Extended `grep` (equivalent to `grep -E`).
* `zgrep`: Used for searching within compressed files.

**Usage:**
```bash
grep <options> <search_pattern> <files>
```

#### Common Options
* `-i`: Ignore case during search
* `-r` / `-R`: Search recursively
* `-v`: Invert match (returns lines that do **not** match)
* `-l`: List file names with matching patterns
* `-L`: List file names without matching patterns
* `-n`: Display line numbers along with output
* `-A <num>`: Print `<num>` lines after matching line
* `-B <num>`: Print `<num>` lines before matching line

#### `grep` Examples

* **Search files containing "bash" in current directory:**
  ```bash
  grep bash *
  ```
* **Search files NOT containing "bash":**
  ```bash
  grep -v bash *
  ```
* **Case-insensitive search with line numbers:**
  ```bash
  grep -in bash *
  ```
* **Logical OR Search:**
  ```bash
  grep 'Man\|Sales' employee.txt
  ```
* **Logical AND Search:**
  ```bash
  grep -i 'sys.*Tech' employee.txt
  ```

### 2. `sed` (Stream Editor)

`sed` is used to parse and transform text. It operates line-by-line and supports regular expression matching and substitution.

| Flag / Command | Operation |
| :--- | :--- |
| `-e` | Combine multiple commands |
| `-f` | Read commands from file |
| `-n` | Disable automatic printing |
| `s` | Substitution command |
| `g` | Global replacement |
| `p` | Print line |
| `d` | Delete line |

#### `sed` Examples

* **Delete blank lines from a file:**
  ```bash
  sed '/^$/d' shub.sh
  ```
* **Delete lines n through m (e.g., lines 2 to 4):**
  ```bash
  sed '2,4d' shub.sh
  ```
