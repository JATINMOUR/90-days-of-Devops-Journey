### User Defined Variables (UDV)

Created and maintained by the user. 

**Example (`user_defined_variables.sh`):**
```bash
#!/bin/bash
trainingCourse="DevOps"
echo "Displaying the user defined variable (trainingCourse) value is: $trainingCourse"
```

## Command Line Arguments

Values passed to a shell script at runtime through the command prompt are called **command line arguments**.

* Arguments are separated by space.
* You can pass an arbitrary number of arguments.

### Special Parameters

| Parameter | Description |
| :--- | :--- |
| `$#` | Number of command-line arguments passed |
| `$$` | Process ID (PID) of the current shell/script |
| `$0` | Name of the current script |
| `$1`, `$2`, `$3` | Positional parameters (1st, 2nd, 3rd argument) |
| `$*` | All command-line arguments as a **single text string** |
| `$@` | All command-line arguments as **separate strings** |

**Example (`commandlineargs.sh`):**
```bash
#!/bin/sh
echo '$#:' $#
echo '$$:' $$
echo '$3:' $3
echo '$0:' $0
echo '$*:' $*
echo '$@:' $@
```

**Run:**
```bash
sh commandlineargs.sh Github Bluemix UCD Jenkins Java Linux
```

**Output:**
```text
$#: 6
$$: 16955
$3: UCD
$0: commandlineargs.sh
$*: Github Bluemix UCD Jenkins Java Linux
$@: Github Bluemix UCD Jenkins Java Linux
```
