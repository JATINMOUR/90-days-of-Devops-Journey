# 2. Introduction & Purpose of Docker

- **Platform Overview:** Docker is a Platform as a Service (PaaS) created in 2013 (first presented at PyCon) to build, package, ship, and run applications in isolated environments called **Containers**.
- **Core Purpose:**
  - Packages an application along with all its dependencies, system tools, libraries, and code.
  - Guarantees consistency across all environments (*"works on my machine"* problem solved across Dev, QA, Staging, and Production).
  - Saves setup time, speeds up development, and streamlines CI/CD pipelines.
