# 5. Docker Terminologies


- **Image:** A read-only template containing instructions to create a container.
- **Container:** A runnable, isolated instance created from a Docker Image.
- **Dockerfile:** A text file containing sequential commands used by Docker to build an image automatically.
- **Registry:** Centralized storage service used to host and share images (e.g., Docker Hub).
- **Repository:** A collection of related images with different tag versions.
- **Volume:** A persistent data storage mechanism independent of container lifecycles.
- **Network:** System enabling communication between containers, host machines, and external endpoints.
