## 7. Helpful GitHub Workflows

### Creating a Pull Request (PR)

1. Push your branch to GitHub:
   ```bash
   git push origin <Your_branch>
   ```
2. Open the repository on GitHub.
3. Navigate to the **Pull Requests** tab and click **New Pull Request**.
4. Select the target branch and source branch, then submit the PR.

### GitHub Fork & Sync Workflow

1. **Fork a Repository:** Click **Fork** on the upstream GitHub repository page.
2. **Clone the Fork:**
   ```bash
   git clone https://github.com/your-username/repo-name.git
   ```
3. **Sync Upstream Changes:**
   ```bash
   git remote add upstream https://github.com/original-owner/repo-name.git
   git fetch upstream
   git merge upstream/main
   ```

## 8. Git Aliases

Speed up daily command-line workflows by defining shorthand shortcuts:

```bash
git config --global alias.co checkout
git config --global alias.br branch
git config --global alias.ci commit
```
