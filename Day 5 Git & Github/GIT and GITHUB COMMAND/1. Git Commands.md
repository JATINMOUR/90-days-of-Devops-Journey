## 1. Installation & Account Setup

* **Git Installation:** Refer to OS-specific installation guides for Windows, macOS, or Linux.
* **Setting Up a GitHub Account:** Create an account on GitHub to host and share code repositories.

## 2. Git Configuration Commands (`git config`)

Configure global credentials and view existing configuration settings.

| Command | Description |
| :--- | :--- |
| `git config --global user.name "<name>"` | Sets the global username for Git commits. |
| `git config --global user.email "<email>"` | Sets the global email address for Git commits. |
| `git config --list` | Displays the current Git configuration (user details, editor, etc.). |

---

## 3. Repository Management

Initialize local projects or mirror existing repositories from remote platforms.

| Command | Description |
| :--- | :--- |
| `git init` | Initialize a new, empty Git repository in the current directory. |
| `git clone <repo>` | Clone an existing repository to your local machine. |
| `git remote -v` | View linked remote repository URLs. |
| `git remote add origin <url>` | Link a local repository to a remote Git repository URL. |

---

## 4. Git Status Command

Track the current status of files in your workspace.

| Command | Description |
| :--- | :--- |
| `git status` | Shows the current status of the working directory and staging area (tracked, modified, untracked, or staged files). |

---

## 5. Adding and Committing

Stage modifications and record changes in the project history.

| Command | Description |
| :--- | :--- |
| `git add <file>` | Stage a specific file for the next commit. |
| `git add .` | Stage all modified and new files across the directory. |
| `git commit -m "message"` | Commit staged changes with a descriptive log message. |
| `git commit --amend` | Modify or update the last commit (message or staged files). |

---

## 6. Branching and Merging

Manage isolated development workflows.

| Command | Description |
| :--- | :--- |
| `git branch` | List all local branches in the repository. |
| `git branch <branch>` | Create a new branch. |
| `git checkout <branch>` | Switch workspace to an existing branch. |
| `git checkout -b <branch>` | Create a new branch and immediately switch to it. |
| `git merge <branch>` | Merge the specified branch into the currently active branch. |
| `git branch -d <branch>` | Delete a local branch. |

---

## 7. Log and History

Inspect repository commit history and file diffs.

| Command | Description |
| :--- | :--- |
| `git log` | Display full commit history. |
| `git log --oneline` | View condensed commit history (one line per commit). |
| `git diff` | View unstaged changes in the working directory. |
| `git diff HEAD` | Compare current working directory changes directly against `HEAD`. |

---

## 8. Undo Changes

Unstage modifications, restore files, or revert project commits.

| Command | Description |
| :--- | :--- |
| `git reset <file>` | Unstages a file while keeping modifications in the working directory. |
| `git restore <file>` | Restores a file in the working directory to its last committed state. |
| `git reset --hard <commit>` | Resets current branch to a specified commit and discards all local changes. |
| `git revert <commit>` | Creates a new commit that safely safely negates changes from a previous commit. |

---

## 9. Pushing, Pulling, and Fetching

Sync code between local and remote repositories.

| Command | Description |
| :--- | :--- |
| `git push origin <branch>` | Push local commits to the specified remote repository branch. |
| `git pull origin <branch>` | Fetch and merge changes from the remote repository branch. |
| `git fetch` | Download commits, files, and refs from a remote repository without merging
