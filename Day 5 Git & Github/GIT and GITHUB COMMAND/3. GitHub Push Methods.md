## 6. GitHub Push Methods

### Method 1: SSH Method

1. **Generate SSH Key:**
   ```bash
   ssh-keygen
   ```
2. **Copy the Public Key:**
   ```bash
   cat ~/.ssh/<key_name>.pub
   ```
3. **Configure GitHub:** Navigate to **GitHub > Settings > SSH and GPG keys > New SSH key**, then paste and save your key.
4. **Verify Connection:**
   ```bash
   ssh-T git@github.com
   ```
5. **Clone & Push:** Clone your repository using the SSH URL, make and commit your changes, then push:
   ```bash
   git push origin main
   ```

### Method 2: HTTPS Method

1. **Generate Personal Access Token (PAT):** Create a token via **GitHub Settings > Developer Settings > Personal Access Tokens**.
2. **Update Remote URL:**
   ```bash
   git remote set-url origin https://<Your_PAT>@github.com/<username>/<repository>.git
   ```
3. **Commit & Push:**
   ```bash
   git push origin main
   ```
