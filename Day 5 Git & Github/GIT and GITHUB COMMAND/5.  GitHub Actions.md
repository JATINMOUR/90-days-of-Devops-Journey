## 9. GitHub Actions (CI/CD)

**Significance:** Automates workflow processes such as building, testing, and deploying applications directly on GitHub events.

### Example Workflow Configuration (`.github/workflows/main.yml`)

```yaml
name: CI/CD Pipeline          # Name of the workflow

on:
  push:                       # Trigger workflow on push to the main branch
    branches:
      - main
  pull_request:               # Trigger workflow on PR to the main branch
    branches:
      - main

jobs:
  build:                      # Define a job named 'build'
    runs-on: ubuntu-latest    # Use the latest Ubuntu environment
    steps:
      - name: Checkout Code
        uses: actions/checkout@v2

      - name: Install Dependencies
        run: npm install

      - name: Run Tests
        run: npm test
```

> **Description:** Automatically checks out code, installs dependencies, and executes unit tests on every `push` or `pull_request` targeting the `main` branch.
